# SplitForge Releases

Official Windows installer releases for **SplitForge**.

## Download

The current production installer is published in the latest GitHub Release as:

`SplitForge-Setup.exe`

Permanent latest-download address:

`https://github.com/Ncarr22/SplitForge-Releases/releases/latest/download/SplitForge-Setup.exe`

SplitForge is licensed software. After installation, customers activate with the same email used at checkout plus the Lemon Squeezy license key delivered with their purchase.

This repository contains compiled release files only. The SplitForge source/build repository is private.
